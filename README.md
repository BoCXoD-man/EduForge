# EduForge

**EduForge** — инструмент для автоматической генерации учебных материалов по программированию с помощью AI.

Проект был разработан в первую очередь как практический инструмент для моей текущей работы: я занимаюсь обучением программированию и использую EduForge для создания методичек, которые затем могу использовать в учебном процессе и предоставлять своим студентам.

Одновременно проект является моим pet-project для развития навыков Python-разработки и практического применения AI-технологий.

---

## Откуда название?

Название **EduForge** образовано от двух слов:

* **Edu** — сокращение от *Education* — образование;
* **Forge** — кузница, место, где что-то создаётся и формируется.

Таким образом, **EduForge** можно условно перевести как **«кузница образования»** или **«кузница учебных материалов»**.

Идея названия хорошо отражает назначение проекта: взять исходную тему и превратить её в полноценный структурированный учебный материал.

---

## Возможности

EduForge позволяет:

* генерировать учебные методички по заданной теме;
* выбирать AI-провайдера;
* создавать материалы на русском или английском языке;
* сохранять результат в Markdown (`.md`);
* экспортировать результат в PDF (`.pdf`);
* получать структурированный материал с объяснениями и примерами;
* генерировать ровно 5 практических заданий с постепенным увеличением сложности.

Поддерживаемые AI-провайдеры:

* OpenAI;
* Google Gemini;
* OpenRouter.

## Как работает EduForge

Общий процесс генерации выглядит следующим образом:

```text
Пользователь
     │
     ▼
  PySide6 GUI
     │
     ▼
GenerationWorker
     │
     ▼
MethodologyGenerator
     │
     ▼
  ModelFactory
     │
     ├──────────────┬──────────────┐
     ▼              ▼              ▼
  OpenAI         Gemini       OpenRouter
     │              │              │
     └──────────────┴──────────────┘
                    │
                    ▼
             Готовая методичка
                    │
             ┌──────┴──────┐
             ▼             ▼
          Markdown        PDF
```

Пользователь выбирает тему, AI-провайдера, язык и формат результата.

`MethodologyGenerator` загружает системный prompt, формирует запрос и передаёт его выбранной AI-модели.

Полученный результат представляет собой единый Markdown-текст. После этого он может быть сохранён непосредственно в `.md` либо преобразован в PDF.

## Структура учебной методички

EduForge использует общий системный prompt, который задаёт структуру создаваемого материала.

Методичка состоит из следующих разделов:

1. **Введение**
2. **Основные понятия**
3. **Примеры**
4. **Практические задания**
5. **Итоги**

Практическая часть содержит **ровно 5 заданий** с постепенным увеличением сложности.

Каждое задание включает:

* название;
* условие;
* требования;
* ожидаемый результат.

Готовые решения задач не предоставляются, если пользователь отдельно их не запросил. Это позволяет использовать сгенерированные задания непосредственно в учебном процессе.

### Основные компоненты

**`main.py`**

Точка входа приложения. Загружает переменные окружения, создаёт Qt-приложение и запускает главное окно.

**`models.py`**

Содержит общий интерфейс AI-моделей и реализации для OpenAI, Gemini и OpenRouter.

Также здесь находится `ModelFactory`, которая создаёт нужную реализацию модели на основе выбранного AI-провайдера.

**`generator.py`**

Отвечает за генерацию учебной методички. Загружает системный prompt, формирует пользовательский запрос и передаёт его выбранной AI-модели.

**`gui/main_window.py`**

Главное окно приложения. Позволяет выбрать AI-провайдера, язык, формат и тему методички.

**`gui/worker.py`**

Выполняет генерацию в отдельном потоке Qt, чтобы длительный сетевой запрос к AI не блокировал пользовательский интерфейс.

**`tools/file_tools.py`**

Отвечает за сохранение методичек в Markdown и PDF.

## Экспорт в PDF

PDF создаётся на основе того же Markdown, который возвращает AI:

```text
Markdown
   ↓
HTML
   ↓
QTextDocument
   ↓
QPrinter
   ↓
PDF
```

Markdown преобразуется в HTML с помощью библиотеки `Markdown`, после чего Qt формирует PDF-документ.

Такой подход позволяет сохранить форматирование заголовков, списков, таблиц и блоков кода без необходимости использовать отдельный внешний PDF-движок.

## Установка

Для работы проекта требуется Python.

Клонируйте репозиторий:

```bash
git clone https://github.com/BoCXoD-man/EduForge.git
cd EduForge
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

---

## Настройка API-ключей

Создайте файл `.env` в корне проекта.

Пример:

```env
OPENAI_API_KEY=your_openai_api_key
GEMINI_API_KEY=your_gemini_api_key
OPENROUTER_API_KEY=your_openrouter_api_key
```

---

## Запуск

Из корневой директории проекта:

```bash
python main.py
```

После запуска откроется интерфейс EduForge.

Выберите:

1. AI-модель;
2. язык методички;
3. формат результата;
4. тему.

После нажатия **«Создать методичку»** приложение отправит запрос выбранной AI-модели и сохранит результат в директорию `output`.

## Архитектурные особенности

При разработке EduForge основной целью было разделить ответственность компонентов.

GUI отвечает за взаимодействие с пользователем, но не содержит логику работы с конкретными AI-провайдерами.

AI-модели реализуют общий интерфейс `BaseModel`, благодаря чему конкретного провайдера можно заменить без изменения основной логики генерации.

`ModelFactory` изолирует создание конкретной реализации AI-модели.

Генерация выполняется через `QThread`, поэтому длительный сетевой запрос не блокирует основной поток Qt.

Работа с файлами вынесена в отдельный модуль. Это позволяет добавлять новые форматы экспорта без существенных изменений GUI.

## Почему проект был создан

Изначально EduForge появился из практической задачи.

При подготовке занятий необходимо регулярно создавать учебные материалы: объяснения новых тем, примеры и практические задания для студентов. Значительная часть этой работы повторяется из занятия в занят и требует времени.

EduForge автоматизирует часть этого процесса.

Вместо того чтобы каждый раз создавать методичку с нуля, достаточно указать тему и параметры материала. AI формирует основу учебного материала, которую затем можно использовать непосредственно в работе со студентами или доработать под конкретное занятие.

При этом проект остаётся инструментом преподавателя, а не заменой преподавательской работы: итоговый материал можно проверить, изменить и адаптировать перед использованием.

## Цель проекта

EduForge одновременно решает две задачи.

**Практическая задача** — ускорить подготовку учебных материалов для реального использования в работе со студентами.

**Задача разработки** — получить полноценный проект, на котором можно практически применять и развивать навыки:

* Python;
* работы с внешними API;
* интеграции AI-моделей;
* разработки GUI;
* многопоточности в Qt;
* проектирования программной архитектуры;
* работы с файловыми форматами;
* обработки ошибок;
* конфигурации приложения через переменные окружения.
